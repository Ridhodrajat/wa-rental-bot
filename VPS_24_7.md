# Cara Menjalankan Bot 24/7 di VPS

Panduan ringkas & berurutan. Untuk detail lengkap lihat `DEPLOYMENT.md`.

> **Ringkasan:** Beli VPS → install Node 24 → clone repo → set `.env` → build →
> jalankan dengan PM2 → scan QR → `pm2 save`. Selesai.

---

## 0. Yang kamu butuhkan

| Item | Keterangan |
|------|-----------|
| VPS | Ubuntu 22.04 / 24.04, RAM **min 1GB** (disarankan 2GB) |
| Nomor WhatsApp | Nomor khusus untuk bot (bukan nomor pribadi utama) |
| SSH client | Terminal / PuTTY / Termius |

Rekomendasi penyedia VPS: DigitalOcean, Vultr, Contabo, Hetzner, Idcloudhost,
Biznet Gio. Harga mulai ~Rp 30–50 ribu/bulan untuk 1GB RAM.

---

## 1. Login ke VPS & update sistem

```bash
ssh root@IP_VPS_ANDA

apt update && apt upgrade -y
apt install -y curl git nano
```

---

## 2. Install Node.js 24 LTS (WAJIB versi ini)

> ⚠️ Bot ini memakai **`node:sqlite` bawaan Node.js**. Node 24 = stabil tanpa flag.

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | bash -
apt install -y nodejs

node -v   # harus v24.x (minimal v22.5.0)
npm -v
```

---

## 3. Clone project

```bash
cd ~
git clone https://github.com/Ridhodrajat/wa-rental-bot.git
cd wa-rental-bot
npm install
```

> Repo bersifat **private**, jadi siapkan akses. Cara termudah: buat
> Personal Access Token (PAT) di GitHub → Settings → Developer settings →
> Personal access tokens, lalu gunakan sebagai password saat `git clone`.
> Alternatif: upload manual via `scp` dari komputer.

---

## 4. Buat file `.env`

```bash
cp .env.example .env
nano .env
```

Isi (sesuaikan `OWNER_NUMBER`):

```env
OWNER_NUMBER=6289510214771
OWNER_NAME=Owner
BOT_PREFIX=.
DATABASE_PATH=./data/bot.sqlite
AUTH_DIR=./auth
MEDIA_DIR=./media
LOG_LEVEL=info
NODE_ENV=production
TZ_DISPLAY=Asia/Jakarta
ANTIPRIVATE_ENABLED=true
PRIVATE_MESSAGE_LIMIT=5
AUTO_BLOCK_ENABLED=false
MAX_MEDIA_SIZE=5242880
```

Simpan: `Ctrl+O` → Enter → `Ctrl+X`.

---

## 5. Build project

```bash
npm run build
```

---

## 6. Install PM2 (agar bot otomatis restart)

```bash
npm install -g pm2

# Aktifkan auto-start saat VPS reboot
pm2 startup
# → jalankan perintah yang ditampilkan PM2 (copy-paste)
```

---

## 7. Jalankan bot

```bash
mkdir -p logs
pm2 start ecosystem.config.js
pm2 save
pm2 status
```

---

## 8. Scan QR WhatsApp

```bash
pm2 logs wa-rental-bot --lines 100
```

Scan QR di log dengan WhatsApp:
**WhatsApp → Setelan → Perangkat Tertaut → Tautkan Perangkat**

Setelah muncul `Bot terkoneksi ke WhatsApp`, tekan `Ctrl+C` untuk keluar dari log
(bot tetap jalan).

---

## 9. Cek bot berjalan

```bash
pm2 status              # status harus "online"
pm2 logs wa-rental-bot  # lihat log realtime
```

Di WhatsApp, kirim `.menu` ke grup → bot harus membalas.

---

## Perintah PM2 yang sering dipakai

```bash
pm2 status                    # lihat status
pm2 logs wa-rental-bot        # log realtime
pm2 logs wa-rental-bot --lines 200
pm2 restart wa-rental-bot     # restart
pm2 stop wa-rental-bot        # stop
pm2 monit                     # monitor CPU/RAM
```

---

## Update bot (setelah ada perubahan kode)

```bash
cd ~/wa-rental-bot

# Backup dulu
cp data/bot.sqlite backups/backup-$(date +%Y%m%d).sqlite

git pull origin main
npm install
npm run build
pm2 restart wa-rental-bot
```

---

## Keamanan dasar (disarankan)

```bash
apt install -y ufw
ufw allow 22/tcp
ufw enable

# Amankan file sensitif
chmod 600 .env
chmod 700 auth/ data/ backups/ media/
```

## Troubleshooting umum

| Masalah | Solusi |
|---------|--------|
| `node:sqlite` tidak ditemukan | Node terlalu lama → install Node 24 |
| Bot disconnect terus / `Bad MAC` | Ada 2 instance jalan. `pm2 delete all` lalu `pm2 start ecosystem.config.js` |
| `Database locked` | Sama: pastikan hanya 1 instance |
| QR tidak muncul | `pm2 logs wa-rental-bot --lines 200`, tunggu 10–20 detik |
| Sesi logout / minta QR ulang | `pm2 stop wa-rental-bot; rm -rf auth/; pm2 start ecosystem.config.js` lalu scan ulang |
| Bot tidak balas | Cek `pm2 logs`, pastikan grup sudah disewa (`.ceksewa`) |

> ⚠️ **JANGAN** jalankan bot dengan folder `auth/` yang sama di 2 tempat
> (mis. sekaligus di laptop dan VPS). Ini menyebabkan sesi konflik & logout.
