Panduan Menggunakan Bot

Dari pemesanan sampai bot siap melayani grup — semua langkahnya ada di sini.

1. Cara Pesan / Sewa

  1. 1

    Hubungi Owner

    Klik tombol WhatsApp di situs ini, lalu sampaikan kamu ingin menyewa bot.

  2. 2

    Pilih Paket & Bayar

    Tentukan durasi sewa. Pembayaran langsung ke owner (di luar bot).

  3. 3

    Owner Mengaktifkan Sewa

    Setelah pembayaran, owner mengaktifkan masa sewa untuk grupmu.

  4. 4

    Undang Bot & Jadikan Admin

    Undang nomor bot ke grupmu, lalu jadikan bot sebagai admin grup.

  5. 5

    Siap Dipakai

    Ketik perintah menu di grup dan mulai atur katalog serta templatemu.

Sewa bersifat kumulatif. Contoh format durasi: 7h (7 hari), 30h (30 hari), 4w (4 minggu), 2j (2 jam).

2. Persiapan untuk Admin Grup

  1. 1

    Jadikan bot admin

    Tanpa hak admin, fitur moderasi dan pengaturan grup tidak bisa dipakai.

  2. 2

    Lihat menu

    Ketik perintah menu untuk melihat seluruh perintah sesuai hak aksesmu.

  3. 3

    Susun katalog

    Tambah produk dengan format nama dan deskripsi dipisah tanda pipa ( | ).

  4. 4

    Atur template

    Pilih gaya pesan proses, selesai, welcome, dan goodbye sesuai selera tokomu.

  5. 5

    Jadwalkan buka/tutup

    Atur jam buka dan tutup grup agar otomatis setiap hari.

  6. 6

    Aktifkan laporan

    Hidupkan laporan order agar ringkasan pendapatan terkirim tiap grup ditutup.

3. Alur Jual-Beli Harian

  1. Pelanggan melihat katalog, lalu mengetik nama produk untuk melihat detailnya.
  2. Pelanggan memesan dan membayar (di luar bot, sesuai kebijakan toko).
  3. Admin membalas chat pelanggan, lalu mengirim status diproses.
  4. Setelah selesai, admin membalas chat pelanggan lalu mengirim status selesai beserta nominalnya (contoh: .done 50000) agar pesanan tercatat.
  5. Admin dapat mengunduh laporan pendapatan kapan saja.

4. Pertanyaan Umum (FAQ)

Apakah bot butuh nomor WhatsApp baru?

Sebaiknya ya. Gunakan nomor khusus untuk bot agar tidak mengganggu nomor pribadimu.

Berapa banyak grup yang bisa dilayani?

Bot bersifat multi-grup. Setiap grup memiliki katalog, template, dan pengaturan sendiri, serta bisa disewa terpisah.

Apakah aman dipakai?

Bot bekerja seperti aplikasi WhatsApp Web yang tertaut pada satu nomor. Karena memakai library tidak resmi, gunakan secara wajar dan hindari spam.

Bisa berhenti kapan saja?

Bisa. Cukup tidak memperpanjang sewa. Grup dinonaktifkan, dan data grup dihapus otomatis setelah masa tenggang berakhir.

Data grup saya dilihat owner?

Owner hanya mengelola masa sewa dan teknis bot. Katalog, template, dan laporan order tersimpan terpisah per grup.

Bagaimana kalau bot terputus?

Owner akan menautkan ulang sesi WhatsApp. Selama bot terdaftar, kamu bisa menghubungi owner untuk pemulihan.

Apakah bisa laporan pendapatan?

Bisa. Catat order sambil mengirim status selesai, lalu unduh laporan harian, mingguan, atau bulanan dalam format Excel.

Bagaimana cara pesan produknya?

Pelanggan cukup mengetik nama produk di grup. Bot otomatis membalas deskripsi dan foto produk tersebut.

5. Kendala yang Sering Terjadi

Bot tidak membalas di grup

Pastikan masa sewa grup masih aktif dan kamu memakai perintah sesuai hak akses.

Muncul pesan bot harus admin

Jadikan bot sebagai admin grup terlebih dahulu dari menu pengaturan grup WhatsApp.

Fitur moderasi tidak jalan

Pastikan fitur sudah diaktifkan dan bot adalah admin grup.

Katalog tidak muncul

Tambahkan produk terlebih dahulu, lalu jalankan perintah daftar produk.

Import katalog gagal

Pastikan format file benar (Excel dua kolom, atau teks dengan pemisah pipa) dan kamu admin/owner.

Masih ada pertanyaan?

Hubungi owner langsung, dijawab secepatnya.
